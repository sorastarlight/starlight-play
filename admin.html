Mix It Up link

This hub does not replace Mix It Up. A small bridge on the stream PC runs the same Python Mix It Up already uses, then publishes the overlay encounter to Play.

  1. Click create token once, then copy it.
  2. Copy Data/play-bridge.example.json to Data/play-bridge.json and paste the token.
  3. Run MixItUp/Start-Play-Bridge.bat (or the Mix It Up action group Play - Start Stream Bridge) and leave it running while you stream.

Enable Twitch login for Play Keep this app separate from the card binder.
  1. Open the Twitch Developer Console and register Starlight Play.
  2. Category: Website Integration. OAuth Redirect URL:
    https://dtflmlbjhttoewqgkujf.supabase.co/auth/v1/callback
