@GlubbusI don't know if this game runs on unity, but since the mobile Pokémon games I've found run on unity, here's how you do it if it runs on unity:
First, change the APK file to a ZIP if it's an android game, and extract the files. There may be more than one APK file.
Second, open up AssetStudio and open the extracted folder, not the exact folder that's probably labeled "assets". (That way, you won't miss anything)
Third, since you're wanting to rip models, go into Filter and change it to only show the "Mesh" files.
Hope this helps!
If it doesn't, reply back and I'll see if I can help.
EDIT 3/21/2022: I thought I edited this comment a while back, but I guess it's better late than never...
So when I looked into the game's files, I found out that either the game's files are downloaded onto your device or it's simply not a Unity game. If it isn't a Unity game, then the method I mentioned above won't work. Sorry if I caused any disappointment.|
