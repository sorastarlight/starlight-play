## flash_on Actions

The building blocks of every automation: chain as many as you like inside any command.

### Chat Action

Send a message to chat from your streamer or bot account, as a reply or a whisper, to every connected platform at once.

### Platform Message Action

Send a chat message to one specific platform instead of all of them, with its own Send As Streamer option.

### Command Action

Put your commands in charge of other commands. Run, pause, enable, disable, or reset a command automatically as part of any automation.

### Conditional Action

Add logic to your automations. Only do something if a condition is true, and loop it, branch it, or combine multiple checks with AND/OR/XOR.

### Consumables Action

Award or deduct currency and inventory items as part of any command. Give out points for a great moment or charge viewers to participate.

### Counter Action

Increment, decrement, reset, or set a named counter whenever you need to track something: deaths, hype moments, hydration breaks, anything.

### External Program Action

Launch any app or script as part of your automation and optionally capture what it outputs to use in the same command.

### File Action

Read and write text files on the fly, update a scoreboard, pull a name from a list, or log data to a file automatically.

### Game Queue Action

Control who's up next without lifting a finger. Add, remove, shuffle, or select viewers from the game queue automatically.

### Group Action

Bundle actions together into a single organized block. Keeps complex commands clean and easy to follow.

### Input Action

Simulate a keypress or mouse click, useful for triggering hotkeys in games or controlling software without switching windows.

### Moderation Action

Timeout, ban, purge, or mod users automatically as part of any command.

### Music Player Action

Control your stream music from anywhere. Skip a track, change the volume, or swap playlists automatically as part of a command.

### Overlay Action

Trigger any overlay effect from a command: show an image, play a sound, spin the wheel, or update a goal bar, at exactly the right moment.

### Random Action

Add a little chaos. Mix It Up picks one path at random from several options you define, each with its own weighted odds.

### Repeat Action

Do something once, or do it a hundred times. Repeat any set of actions as many times as you need, even based on a dynamic value.

### Script Action

Run a custom script in C#, Python, or JavaScript and feed the result right back into your command. Total flexibility for power users.

### Sound Action

Play any sound on any output device, or stop everything that's playing, all as part of a command.

### Special Identifier Action

Create a custom variable on the spot and use it anywhere downstream in the same command. Great for storing calculated or fetched values mid-automation.

### Streaming Software Action

Switch scenes, toggle sources, update overlays, and start or stop your stream, all without touching OBS, Streamlabs, or XSplit manually.

### Text-to-Speech Action

Give your stream a voice. Read out chat messages, donation alerts, or any text you choose using your preferred TTS engine and voice.

### User Lookup Action

Find a viewer on any platform by username or ID and use their name, ID, and avatar in the rest of the command.

### Wait Action

Add a pause between actions. Give an animation time to finish, a message time to land, or just control the pacing of your automation.

### Web Request Action

Fetch data from any API and use the result in your command. Prices, weather, sports scores: if it has an API, you can pull it into your stream.

## rule Command Requirements

Fine-grained control over who can run each command, and what it costs them.

### Role Requirement

Set the minimum role a command needs, anywhere from follower to moderator. Everyone below it stays locked out automatically.

### Cooldown Requirement

Keep commands from being spammed. Set a shared cooldown for everyone or an individual timer per viewer, with clear feedback when they try too soon.

### Currency Requirement

Make viewers spend points to use a command. Set a fixed cost or let them choose how much to put in, with optional minimums and maximums.

### Inventory Requirement

Require viewers to hold a specific item before they can use a command, and consume it automatically on use.

### Rank Requirement

Gate commands by rank tier. Unlock features for your most loyal viewers as they climb the leaderboard.

### Threshold Requirement

Some things should only happen when enough people want them. Require a minimum number of viewers to trigger a command together before it fires.

### Arguments Requirement

Add typed inputs to your commands, whether usernames, numbers, or custom text. Mix It Up validates them before the command runs.

### Settings Requirement

Fine-tune how a single command behaves: delete the triggering message, skip deletion, or add it to the right-click context menu, without changing your global settings.
